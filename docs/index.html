Overview & Architecture

High-level modernization architecture on IBM zLinux / WAS Liberty

Mainframe Java Production Ready

Driver License Issuance System (DLIS)

Mainframe modernization enterprise Java application running on zLinux under IBM WebSphere Application Server Liberty. Combines JAX-RS REST endpoints, JCICS mainframe transaction bridging, and high-performance IBM DB2 persistence.

Enterprise Runtime

Targeted for IBM zSystems zLinux executing WebSphere Liberty 23.x with Jakarta EE 8 and Java 11 LTS.

Liberty Profile Configured

High-Throughput CICS Integration

JCICS byte-serialized COMMAREA adapters allow legacy COBOL/3270 programs to call Java core services.

Transactions: CAND, APPL, PAAP

Industrial Database

DB2 for z/OS v12+ & DB2 LUW 11.5 with full relational DDL, sequence generators, and check constraints.

Schema: DLIS (7 Tables)

Core Business Rule Catalog

Age Eligibility Criteria BR-ELIG-001
Candidates must satisfy age constraints: Learner License (L) $\ge 16$ years, Probation License (P) $\ge 17$ years, Open License (O) $\ge 18$ years.
Progressive Tier Upgrade Path BR-ELIG-002
Probation (P) applicants must hold an active Learner (L) license. Open (O) applicants must hold an active Probation (P) license.
Driving History & Demerit Point Cap BR-HIST-001..004
Application rejected if applicant has active suspension/disqualification, unpaid fines, or accumulated demerit points exceeding 12 points.
Dual-Level Authority Approval BR-APPR-001..002
Mandatory segregation of duties: First signoff requires Level 1 Authority; Second signoff requires Level 2 Supervisor authorized for the license type.
License Expiry & Expiration Periods BR-ISS-003
Validity duration: Learner (1 Year), Probation (2 Years), Open (5 Years). Initialized with 12 demerit points balance.
